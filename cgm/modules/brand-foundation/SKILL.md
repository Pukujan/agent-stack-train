# Brand foundation

Use this module before writing marketing language, a README introduction, a landing page, or a visual campaign.

## Workflow

1. Identify the audience and their current situation.
2. Write the one-sentence job the project helps them complete.
3. Separate the emotional promise from the technical mechanism.
4. List supported claims and the repository evidence for each.
5. List boundaries: what the project does not promise.
6. Define preferred terms, words to avoid, and examples of the intended voice.
7. Store the result in the target repository's `brand-language.json`.

## Quality bar

The foundation should make it possible for a different agent to produce a paragraph that sounds like the same project without copying a fixed paragraph. Prefer concrete human situations over adjectives such as “powerful,” “seamless,” or “revolutionary.”

Never turn a model opinion, aspirational roadmap item, or unverified metric into a current brand claim.
